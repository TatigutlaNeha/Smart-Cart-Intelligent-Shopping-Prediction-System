🛒 SmartCart – Intelligent Shopping Prediction System

📌 Overview

SmartCart is a Machine Learning project that predicts customer purchasing behavior based on user data. This helps businesses understand customer intent and improve product recommendations and marketing strategies.

🚀 Features

📊 Data preprocessing and cleaning
🤖 Machine Learning model training
🔍 Purchase prediction system
📈 Model evaluation with metrics
🧠 End-to-end workflow in Jupyter Notebook

🛠️ Tech Stack

Python
NumPy
Pandas
Scikit-learn
Matplotlib
Seaborn
Jupyter Notebook

⚙️ Installation & Setup

1. Clone the repository
git clone https://github.com/TatigutlaNeha/Smart-Cart-Intelligent-Shopping-Prediction-System
2. Navigate to the project folder
cd SmartCart
3. Install dependencies
pip install -r requirements.txt
4. Run the notebook
jupyter notebook

📦 Requirements

Create a file named requirements.txt and add the following:
